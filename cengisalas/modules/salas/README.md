# Modulo de Salones

Contiene los recursos del frontend de CengiSalas:

- `js/`: agenda, solicitudes, administración, tablero, seguimiento y portal.
- `css/`: estilos de las páginas públicas y autenticadas.

Los archivos HTML permanecen en la raíz porque son las rutas públicas ya
compartidas. La base de datos y funciones del módulo están en
`database/supabase` y `supabase/functions`.
